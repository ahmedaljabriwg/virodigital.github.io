Get set up in a few steps

ViroBuilder is a WordPress plugin. Here's how to install and start designing.

1

Install the plugin

In WordPress, go to Plugins → Add New → Upload Plugin, choose the virobuilder.zip you just downloaded, then activate it.

2

Add your API keys

Open ViroBuilder → AI Settings and add your Anthropic key (for generation) and Pexels key (for photos). Both have free tiers — get them at console.anthropic.com and pexels.com/api.

3

Describe your business

Go to ViroBuilder → Create New Page, describe your business in a sentence or two, and let the AI design your page.

4

Refine by chat & click

Open the editor to click any element and edit it, or describe changes in plain language. Publish when you're happy.
